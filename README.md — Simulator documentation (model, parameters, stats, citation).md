# Airline Overbooking Monte Carlo Simulator
## Cathay Pacific CX344 (HKG → PEK) — Airbus A330-300

**IB Math AA HL Internal Assessment — Data Generation & Simulation**

---

## Overview

This repository contains a **Monte Carlo binomial simulator** that generates realistic flight-level overbooking data for Cathay Pacific flight CX344 (Hong Kong HKG → Beijing PEK), operated by an Airbus A330-300 (A333) with 262 seats.

The simulator models 92 daily flights over the summer peak period (1 June – 31 August 2024) and produces per-flight records including tickets sold, passengers showed up, no-shows, denied boardings (bumped passengers), fares, revenue, and compensation costs.

> **Note:** This is a synthetic dataset generated by mathematical simulation. Real per-flight booking and overbooking records are proprietary airline revenue management data and are not released publicly by airlines or regulators. The simulation parameters are calibrated using industry-typical values.

## The Mathematical Model

### Core Assumptions

| Parameter | Symbol | Value | Description |
|---|---|---|---|
| Aircraft capacity | $C$ | 262 | Airbus A330-300 (39J + 223Y) |
| Show-up probability | $p$ | 0.90 | Probability a booked passenger arrives |
| Average fare | $t$ | HKD 2,400 | Base one-way economy fare |
| Compensation per bump | $b$ | HKD 5,000 | Denied boarding compensation |
| Tickets sold | $N$ | variable | Airline's booking decision (overbooking) |

### Binomial Distribution

Each of the $N$ ticketed passengers independently shows up with probability $p$. The number of passengers who show up, $X$, follows a binomial distribution:

$$X \sim B(N,\; p)$$

$$P(X = k) = \binom{N}{k} p^k (1-p)^{N-k}$$

### Revenue Model

For a single flight:

- **Ticket revenue:** $t \times N$ (all tickets are pre-paid, including no-shows)
- **Passengers bumped:** $\max(0,\; X - C)$
- **Compensation paid:** $b \times \max(0,\; X - C)$
- **Net revenue:** $R = tN - b \cdot \max(0,\; X - C)$

### Monte Carlo Simulation

For each value of $N$, the simulator runs many independent trials:
1. Draw $X \sim B(N, p)$ using a pseudorandom binomial generator
2. Calculate bumped passengers and net revenue for that trial
3. Average across all trials to estimate the expected net revenue $E[R(N)]$

The Law of Large Numbers ensures that with sufficient trials, the sample average converges to the true expected value.

## Realism Features

The simulator incorporates several real-world variations:

- **Day-of-week demand:** Fridays, Saturdays, and Sundays have higher fares (+18%) and higher booking demand
- **Seasonal variation:** Summer peak period (June–August) with higher overall demand
- **Random fare noise:** ±6% random variation around the base fare
- **Variable show-up rate:** $p$ varies slightly day-to-day (±1.2%) around the base of 0.90
- **Occasional underbooking:** Some flights sell below capacity (minimum 93% load factor)
- **Capped overbooking:** Maximum 114% of capacity sold

## How to Run

### Prerequisites
- Python 3.8+
- Required packages: `numpy`, `pandas`

```bash
pip install numpy pandas
```

### Run the simulator
```bash
python3 generate_CX344.py
```

This will regenerate `CX344_HKG-PEK_JunAug2024.csv` and print summary statistics.

### Adjust parameters
Open `generate_CX344.py` and modify the parameters at the top:
- `CAPACITY` — aircraft seat count
- `BASE_FARE` — average ticket price (HKD)
- `COMPENSATION` — denied boarding compensation per passenger (HKD)
- `BASE_P` — base show-up probability
- `START` / `END` — simulation date range
